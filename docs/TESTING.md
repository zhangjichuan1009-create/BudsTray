# 0.9.9 发布检查

本次发布在 Windows 上进行了下列检查，未通过测试命令修改真实耳机设置：

- 协议：36 组认证向量、帧解析、Redmi 元数据、SonoFlow 已有响应样本、ACK 与状态回读区分。
- 设备管理：空列表引导、添加 / 移除、自动与手动协议选择、功能显示选项、配置恢复。
- 界面：30 次菜单生命周期、40 次菜单与卡片切换、尺寸动画、设备列表与设置页动画、快速重复开关、音量拖动与点击、焦点及桌面点击收回。
- 安装：在独立测试目录静默安装、覆盖升级、启动安装后的演示界面、卸载。
- 保留配置：设备列表与另一程序副本的自启动路径保持不变；安装副本的启动清理不会删除指向其他路径的任务。

安装测试使用 `/S /NOAUTORUN /D=独立测试目录`，避免干扰真实正在运行的耳机控制程序。普通双击安装的完整视觉流程、SmartScreen 下载提示、重启后自动启动以及不同 Windows 版本仍需在新机器验收。

Redmi Buds 8 Pro 和 1MORE SonoFlow S 的协议操作已有此前真机证据；本次安装发布没有重新进行全套真机设置往返。其他耳机型号、不同固件及部分高级设置仍需真机验证，不因协议识别成功而宣称全面兼容。
